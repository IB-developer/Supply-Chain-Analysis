# 📦 Supply Chain Performance Dashboard | Power BI + SQL

## 📌 Project Overview

This project presents an interactive **Supply Chain Performance Dashboard** developed using **Power BI** and **SQL** to analyze supplier performance, inventory management, logistics efficiency, and overall business performance.

The dashboard enables stakeholders to monitor key supply chain metrics, identify operational bottlenecks, evaluate supplier efficiency, and support data-driven business decisions.

---

## 🎯 Objectives

- Analyze overall supply chain performance
- Monitor inventory levels and replenishment needs
- Evaluate supplier performance and efficiency
- Analyze logistics costs and transportation modes
- Provide actionable insights through interactive dashboards

---

## 📂 Dataset

The project uses a Supply Chain dataset containing:

- **100 Records**
- **24 Attributes**

Key fields include:

- SKU

- Price
- Revenue Generated
- Manufacturing Cost
- Shipping Cost
- Shipping Carrier
- Transportation Mode
- Stock Levels
- Order Quantities
- Lead Time
- Shipping Time
- Defect Rate
- Location
